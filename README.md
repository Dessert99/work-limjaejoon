## 파일과 입력한 글의 처리

- **이미지 압축·변환과 글자 수 세기**는 브라우저에서 처리합니다. 이미지와 입력한 글을 서버로 보내지 않습니다.
- **PDF·문서 도구**는 파일을 서버로 전송해 처리합니다. 입력 파일은 처리 후 삭제하고, 결과는 다운로드 전송이 끝나면 삭제합니다. 다운로드하지 않은 결과는 완료 후 기본 10분 뒤 삭제합니다.
- 이미지 도구는 미리보기에 사용한 결과 파일을 그대로 다운로드합니다.

## 이용 안내

이미지 도구는 JPG·PNG·WebP를 지원하며 HEIC·SVG와 움직이는 PNG·WebP는 지원하지 않습니다. JPG·WebP의 압축 목표는 이미지에 따라 도달하지 못할 수 있고, PNG는 무손실로 압축합니다.

문서 변환은 원본의 글꼴이나 배치에 따라 결과가 달라질 수 있습니다. 특히 실험 지원하는 HWP·HWPX는 변환 품질이 검증되지 않았으므로 제출 전 결과를 확인하세요.
