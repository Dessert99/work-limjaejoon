# 프로젝트 전용 Ponytail 스킬

- 원본: https://github.com/DietrichGebert/ponytail
- 설치 커밋: `09c434ab73ca43761c5d8b0c5d341926c2fba710`
- 원본 경로: `skills/ponytail*`
- 라이선스: MIT, [LICENSE](LICENSE) 참조
- 설치한 스킬: `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help`

프로젝트 전용 스킬로 설치했다. 코딩 작업에는 `AGENTS.md`에 따라 기본 `full` 모드를 적용한다. Codex에서 직접 호출할 때는 `$ponytail`, `$ponytail-review`처럼 스킬 이름을 사용한다.

이 설치에는 플러그인 훅과 전역 모드 설정이 포함되지 않는다. `ponytail-help`의 플러그인 전용 명령과 전역 설정 안내는 이 설치 방식에 해당하지 않는다. `ponytail-gain`의 수치는 원본 프로젝트의 벤치마크 결과이며 이 프로젝트의 측정값이 아니다.
